## Fixed

- Fixed a Windows startup crash affecting some Intel graphics devices during shader compilation with Vulkan. Windows builds now use DirectX 12 by default to avoid the affected Vulkan compiler path.
- Native builds support the `WGPU_BACKEND` environment variable for troubleshooting, for example `WGPU_BACKEND=vulkan` to explicitly select Vulkan.

This patch is based on 0.3.3 and does not include the features or dependency upgrades under development for 0.4.0.
